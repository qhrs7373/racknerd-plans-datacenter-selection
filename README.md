### 虚拟化、面板和系统镜像

RackNerd 这五档都是 KVM，不是 OpenVZ，意味着可以自己改内核、装 Docker、跑需要独立内核模块的软件。控制面板用的是自研的 ctrl，部署完成后在里面能做的事包括：重启、重装系统、打开 HTML5 VNC 控制台、装一键应用、用 ctrl Network Firewall 设入站规则、重置 root 密码、升级套餐。

系统镜像可选 CentOS、Rocky Linux、AlmaLinux、Fedora、Debian、Ubuntu。需要别的系统可以开工单申请自定义 ISO，VNC 控制台也能用来从自己的镜像安装。这一点对需要特定发行版或者要做网络引导恢复的人比较实用。

ctrl 里还挂了一批一键应用，包括 Docker + Portainer、CyberPanel、CloudPanel、n8n、Coolify、Ollama、LibreChat、AnythingLLM、OpenClaw 等。这些应用对内存有明确要求，直接决定了你该买哪一档：

- **n8n、Coolify**：2GB 内存起就能跑，对应 $35.99/年那档
- **Ollama、LibreChat、AnythingLLM、Hermes Agent**：建议 4GB 起，对应 $59.99/年
- **OpenClaw**：官方要求至少 8GB，只有 $119.99/年那档满足

想在自己 VPS 上跑本地小模型的人，看到 $21.99 就下单会直接卡在内存上。这类需求最低门槛是 4GB 档。

## 官方条款里几个容易踩的点

**不退款。** 官方知识库的原文是：按服务条款，我们不提供退款，也没有退款保证期。立即取消服务同样不退。这一点和很多国内厂商“3 天无理由”“7 天试用”的做法完全不同，下单即视为接受。

**没有免费试用。** 官网没有试用申请入口，最低门槛就是买一档 $21.99 的年付套餐来验证。

**默认无备份。** 服务条款明确写到，除非单独购买备份服务，VPS、独立服务器等产品线不包含托管备份，官方不对数据完整性负责，并建议客户自行保留异地备份。跑正式业务的话，这条要当硬约束对待。

**是无管理服务。** 官方把 ctrl 面板能覆盖的日常操作（开关机、重装、控制台、一键应用、防火墙）和技术支持分开，平台层面的问题 24×7 有人管，服务器内部的软件配置、环境搭建、故障排查不在支持范围内。

**IP 可以换。** 官方知识库单列了“能否更换 IP”的条目，VPS 客户在规定时间内提出申请可以免费处理。具体时限去工单里确认。

**支付方式。** 官方知识库写明支持主流信用卡（AMEX、Discover、VISA 等）。另有中文渠道介绍称同时支持 PayPal、支付宝、银联和加密货币，实际可用选项以结账页显示为准。习惯用支付宝付款的读者，走到结账页再确认一次比较稳妥。

**端口限制。** 官网用户评价里有人提到，RackNerd 不封 25 端口，这在正规商家里不算常见。需要发信的场景可以省掉一层麻烦。
